# 자녀 증여자산 시뮬레이터 — 1단계 설계

작성일: 2026-08-02
브랜치: `feature/child-finance-simulator`

> **현행화 주의 (2026-08-03)**: 이 문서의 일부(수익률 기본값·범위, 참고 수익률 제공 방식,
> 결과 레이아웃, 인출 시점, 검증 방식)는 구현 과정에서 의도적으로 달라졌다.
> 현행 기준과 다음 단계 계획은 `2026-08-03-simulator-phase2-trust-planning-funnel.md` §5 참조.

## 1. 목적

증여한 돈이 아이가 자랄 때까지 어떻게 불어나고, 그 과정에서 세금이 얼마나 붙는지를
**사용자가 스스로 계산해 볼 수 있는 도구**를 만든다. 기존 계약서 생성기(`/`)와 형제 관계인
별도 도구 페이지이며, 가이드 콘텐츠(`/guide/*`)와는 분리한다.

## 2. 핵심 원칙 — 계산만 하고 판단하지 않는다

**"사용자가 조건을 고르면, 그 조건에서 세후 얼마가 남는지 계산만 한다."**
무엇을 고를지는 말하지 않는다. 이 원칙이 두 가지 리스크를 동시에 해결한다.

1. **투자권유 규제 회피** — 특정 상품·종목을 추천하거나 수익을 제시하지 않는다.
2. **유료 매뉴얼 보호** — 매뉴얼 PART 3(자녀 계좌 운용 방식별 판단, 주식 증여 타이밍·이월과세)의
   *판단 기준*은 유료로 남고, 사이트는 *숫자 계산*만 담당한다. 계산해 본 사용자가
   "그래서 우리 애는 뭘 골라야 하지?"라는 질문을 갖게 되어 오히려 매뉴얼 유입 장치가 된다.

### 2.1 투자권유가 되지 않게 하는 설계 장치 (구조로 강제)

의도만으로는 부족하므로 아래를 구현 제약으로 못박는다.

- **수익률에 기본값을 넣지 않는다.** 값은 빈칸으로 두고 placeholder로 형식만 안내한다.
  ("연 8% 기대 가능"류의 제시는 수익 제시에 해당)
- **종목명·상품명·운용사명을 일절 쓰지 않는다.** KODEX/TIGER/VOO 같은 고유명 대신
  "국내 상장 해외지수 ETF" 같은 **유형명**만 사용한다. 실무상 가장 중요한 선.
- **과거 수익률·백테스트를 제공하지 않는다.**
- **우열 표현을 UI에서 배제한다.** "유리한 선택", "추천", 순위 배지, 색상 강조 금지.
  결과는 나란히 나열만 한다.
- **면책 문구**에 투자 관련 문장을 추가한다. 웹 화면에만 표시하고 PDF에는 넣지 않는
  기존 원칙(DISCLAIMER)을 그대로 따른다. (1단계는 PDF 출력 없음)

## 3. 1단계 범위

| 축 | 1단계 포함 | 이후 단계 |
|---|---|---|
| 증여 방식 | 유기정기금, 현금 합산(일시금) | — |
| 계좌 | 일반 위탁계좌 | 연금저축계좌(2단계) |
| 상품 유형 | 국내 상장 ETF(국내주식형), 국내 상장 해외 ETF, 해외 상장 ETF | 개별 주식 국내·해외(3단계) |
| 인출 | 지정 시점 일괄 매도 | 분할 매도 전략 |

### 3.1 비목표 (1단계에서 하지 않는 것)

- **환율 계산** — 모든 금액을 원화로만 다룬다. 실제 해외 상장 ETF의 양도차익은 취득·양도
  시점 환율로 각각 원화 환산해 산출하므로 **환율 변동분이 양도차익에 포함되어 과세**된다
  (주가가 그대로여도 환율이 오르면 세금이 발생). 사용자가 가격상승률에 환율 효과를 포함한
  원화 기준 수치를 넣는다는 전제로만 결과가 유효하며, 이 전제를 화면에 명시한다.
  환율을 별도 입력으로 받으면 입력 부담이 커지고 환율 예측을 요구하게 되어 1단계에서는 제외한다.
- 종합소득세 계산 (금융소득 2,000만 원 초과 시 경고만 표시)
- 증여세 대납에 따른 재증여 계산
- 분할 매도·연도별 250만 원 공제 반복 활용 시뮬레이션
- 상품 추천, 포트폴리오 제안, 과거 수익률 제시
- PDF 출력

## 4. 계산 설계

흐름: `① 증여 평가 → ② 증여세 → ③ 운용(성장) → ④ 매도 세금 → 세후 실수령액`

### 4.1 입력

| 필드 | 비고 |
|---|---|
| 증여 방식 | `annuity` / `lumpSum` |
| 월 지급액·시작일·종료일·지급일 | 유기정기금인 경우 |
| 증여 금액·증여일 | 일시금인 경우 (1단계는 단건) |
| 아이 생년월일 | 미성년 판정 및 인출 시점 계산용 |
| 국내 수익률 | 국내 주식형 ETF에만 적용. 기본값 `0`, 사용자 입력(−20%~+20%) |
| 해외 수익률 | 국내 상장·해외 상장 해외지수 ETF에 공통 적용. 기본값 `0`, 사용자 입력(−20%~+20%) |
| 연 분배율 | **기본값 없음**, 사용자 입력 |
| 인출 시점 | 아이 나이(예: 19세, 30세) |

증여자 관계는 1단계에서 **부모 → 자녀(`'자'`)로 고정**한다. 조부모 증여는 세대생략할증 등
별도 쟁점이 있어 범위에서 제외하고 화면에 명시한다.

**가격상승률과 분배율을 분리해서 받는 이유**: 총수익률 하나로 뭉뚱그리면 국내주식형 ETF가
완전 비과세로 계산되어 왜곡된다. 세 상품의 차이가 정확히 "매매차익이냐 분배금이냐"에서
갈리므로, 분리해야 계산기가 의미를 갖는다.

**국내·해외 수익률을 다시 분리해서 받는 이유**: 한 수익률을 세 상품에 똑같이 적용하면
매매차익이 비과세인 국내 주식형 ETF가 구조적으로 항상 가장 크게 나온다. 이는 계산만 하고
판단하지 않는다는 §2 원칙과 충돌한다. 국내 주식형 ETF에는 국내 수익률을 적용하고, 같은 해외
지수를 서로 다른 계좌·세금 구조로 보유하는 국내 상장 해외 ETF와 해외 상장 ETF에는 반드시 같은
해외 수익률을 적용한다. 따라서 뒤의 두 유형 사이 결과 차이는 오직 세금에서만 생긴다.

### 4.2 ① 증여 평가액

- 유기정기금 → 기존 `evaluateAnnuity()` 재사용 (3% 할인, 20배 상한 규약 그대로)
- 일시금 → 증여 금액 그대로

### 4.3 ② 증여세

기존 `judgeDeduction()`으로 한도 초과분(`excess`)을 구한 뒤 세율을 적용한다.
**현재 도메인에는 세액 계산이 없으므로(한도 판정까지만) 새로 추가한다.**

- 미성년 판정: 증여 시작일 기준 만 나이 < `ADULT_AGE` (기존 `isMinor()` 사용)
- `underTaxMin`(과세표준 < 과세최저한)이면 세액 0
- 세율은 누진 구간 + 누진공제 방식, 신고세액공제 적용

세율표·공제율은 **`src/config.ts` 상수로만 참조**한다(하드코딩 금지 — 기존 원칙).
구체 수치는 §7 검수 항목 확정 후 확정한다.

### 4.4 ③ 운용 (성장)

투자 원금은 **증여재산 평가액이 아니라 실제 이체된 원금**이다.
유기정기금은 매달 나눠 들어오므로 적립식, 일시금은 거치식으로 계산한다.

분배금 세율이 상품 유형마다 다르므로 **성장 경로 자체가 상품별로 달라진다.**
따라서 아래 루프를 **상품 유형 3종에 대해 각각 실행**한다.

연 단위 루프로 처리하며, 취득가액(costBasis)을 함께 추적한다:

```
balance = 0
costBasis = 0
distributionTaxTotal = 0

for 각 연도 (증여 시작 ~ 인출 시점):
    contribution = 그 해 납입액          # 일시금은 첫 해에 전액
    balance    += contribution
    costBasis  += contribution

    distribution = balance × 분배율
    distTax      = distribution × 상품별 분배금 세율
    distributionTaxTotal += distTax

    balance   += distribution - distTax   # 세후 재투자
    costBasis += distribution - distTax   # 재투자분은 취득가액에 산입

    balance × = (1 + 가격상승률)
```

**단순화 가정 (화면에 명시)**
- 분배금은 세후 전액 재투자한다.
- 증여세는 별도 납부하며 투자 원금에서 차감하지 않는다.
  (실무상 미성년 자녀의 증여세는 부모가 대납하는 경우가 많고, 그 대납액도 증여에 해당하나
  1단계에서는 다루지 않는다.)

### 4.5 ④ 매도 시 세금

`capitalGain = balance − costBasis`

| 상품 유형 | 매매차익 | 분배금 |
|---|---|---|
| 국내 상장 ETF(국내주식형) | 비과세 | 배당소득세 |
| 국내 상장 해외 ETF | 배당소득세율 적용(보유기간 과세) | 배당소득세 |
| 해외 상장 ETF | (차익 − 기본공제) × 양도세율 | 해외 원천징수 |

- 해외 상장 ETF는 기본공제 차감 후 음수면 0으로 처리한다.
- 금융소득(분배금 + 국내상장 해외 ETF 차익) 합계가 종합과세 기준을 넘으면 **경고만** 표시하고
  종합과세 계산은 하지 않는다.
- **확인(2026-08-03)**: 소득세법 시행규칙 제13조·제14조에 따르면 국내 상장 해외 ETF의
  배당소득금액은 과세표준기준가격 기준으로 계산한 금액과 실제 매수·매도 가격 기준으로 계산한
  금액 중 **적은 금액**으로 정한다. 과세표준기준가격은 운용사가 매일 고시하는 값이라 미래
  시점의 값을 알 수 없어 이 계산기가 정확히 재현하는 것은 구조적으로 불가능하다. 따라서
  매매차익 전액에 세율을 적용하며, 그 결과 세금은 실제보다 **같거나 많게** 계산될 뿐 적게
  계산되지는 않는다. 이 한계는 화면(상세 내역 설명 문단, 상세 표의 "최대" 표시, 계산의 단순화
  가정 목록)에 명시한다.

### 4.6 출력

```ts
{
  giftPrincipal,    // 실제 이체 총액
  giftValuation,    // 증여재산 평가액
  deduction,        // 한도 판정 (기존 DeductionJudgement)
  giftTax,          // 증여세액
  byProduct: {
    domesticEquityEtf:  { finalValue, costBasis, capitalGain, distributionTax, saleTax, afterTax },
    domesticForeignEtf: { ... },
    overseasEtf:        { ... },
  },
  financialIncomeWarning: boolean,   // 종합과세 기준 초과 여부
}
```

화면에는 단계별 누적으로 표시한다:
`원금 → 평가액 → 증여세 → 성장 후 → 매도 세금 → 세후`

## 5. UI / UX 설계

### 5.1 페이지

- 경로: `/simulator` — 최상위, 가이드와 분리
- **단일 페이지, 위저드 아님.** PDF 생성 같은 무거운 단계가 없으므로 입력을 바꾸면 결과가
  즉시 갱신된다.
- 모바일 우선(인스타 유입). 결과 비교표는 기존 `table-scroll` + `info-table` 패턴 재사용.
- 세 상품 유형을 **나란히** 표시한다. 하나씩 바꿔 돌려보게 하는 것보다 비교가 목적에 맞다.
  단 순위·강조·색상으로 우열을 표시하지 않고 "조건이 바뀌면 결과도 바뀝니다"를 명시한다.

### 5.2 진입 동선 — Step3 단독 + 역방향

**메인 → 시뮬레이터**: 계약서 도구 **Step3 결과 하단 한 곳**에만 진입점을 둔다.
계약서를 막 완성한 사용자는 이미 금액·기간·생년월일을 입력해 둔 상태라 값이 그대로 승계되어
마찰이 0이다. (Step1 보조 진입점은 첫 화면 이탈 우려로 제외 — 사용자 결정)

**시뮬레이터 → 메인**: 결과 하단에 "이 조건으로 계약서 만들기". 금액·기간이 넘어가
Step2가 채워진 상태로 시작된다. 이로써 `계산 → 실행 → 신고`가 하나의 흐름이 된다.

**헤더는 변경하지 않는다.** 도구 페이지의 "증여 가이드" pill에 항목을 더하면 모바일에서
좁아지고 선택 부담이 는다. 진입은 본문 맥락 안에서만 만든다.

### 5.3 값 승계

`sessionStorage`에 별도 키(`gift-sim-handoff-v1`)로 전달한다.

- **URL 쿼리 파라미터를 쓰지 않는다.** 생년월일이 주소창·히스토리·리퍼러에 남으며
  기존 RRN 취급 원칙과 어긋난다.
- 넘기는 값은 **금액·기간·생년월일뿐**. 이름·연락처·주민등록번호는 시뮬레이터가 받지도 않는다.
- 기존 `storage/draft.ts`와 **별개 모듈**로 두어 계약서 임시저장 로직에 영향을 주지 않는다.

### 5.4 가이드 연결

관련도가 가장 높은 **2편에만** 링크한다 — 유기정기금 신고 가이드, 미성년 자녀 주식계좌 가이드.
전체 글에 뿌리면 기존 매뉴얼 CTA·도구 CTA와 겹쳐 산만해진다.

## 7. 세무사 검수가 필요한 항목 (구현 착수 전 확정)

로직에 세법이 직접 들어가므로 아래는 확정 후 상수화한다. 나중에 뒤집히면 계산기 전체를
다시 손봐야 한다.

### 7.1 법령 원문으로 확인 완료 (2026-08-03)

법제처 국가법령정보센터 원문·국세청 자료로 직접 확인했다. 세무사 질의 대상에서 제외한다.

- 국내 상장 해외 ETF 과세 방식 — 소득세법 시행규칙 §13·§14: 과세표준기준가격 기준액과
  실제 매매차익 중 **적은 금액**. 정확 재현 불가라 화면에 한계 명시로 대응 (§4.5).
- 증여세 세율 구간·누진공제액 — 상증세법 §56(§26 준용). 4개 구간 모두 산술 검산 일치.
- 신고세액공제 3% — 상증세법 §69② "100분의 3".
- 증여재산공제 5,000만 / 미성년 2,000만, 10년 통산 — 상증세법 §53.
- 과세최저한 50만 원 미만 — 상증세법 §55②.
- 해외 상장 ETF 양도소득 기본공제 250만 원 — 소득세법 §103①, 국내·국외 **합산** 적용.
- 해외 상장 ETF 양도세율 20% — 소득세법 §104①12나(+지방소득세 = 22%).
- 배당소득 원천징수 14% — 소득세법 §129①2나.
- 지방소득세 부가 방식 — 배당은 지방세법 §103의13①(원천징수 소득세의 100분의 10 특별징수)
  → 15.4%. 양도는 지방세법 §103의3①12나(과세표준의 1천분의 20)로 **독립 표준세율**이며,
  과세표준이 소득세법과 동일하므로(§103②③) 결과는 22%로 같다.
- 미국 배당 원천징수 15% — 한미 조세조약 §12(2)(a) "총배당액의 15퍼센트". (b)의 10%는
  의결권 주식 10% 이상 보유 법인용이라 개인 비해당.
- 조특법 §104의27(고배당기업 특례) — ETF는 투자회사라 대상 아니고 신청주의. **영향 없음.**
- 국세청 예규 서면-2022-법규재산-5398 — 국내 상장 ETF 양도이익은 배당소득이며
  해외 상장분과 통산 불가.

- 해외 상장 ETF 분배금도 국내 원천징수 대상 — 소득세법 §127⑤: 외국법인이 발행한 증권의
  이자·배당은 "국내에서 그 지급을 대리하거나 그 지급 권한을 위임·위탁받은 자"(증권사)가
  원천징수한다. 따라서 §14③6의 "원천징수된 소득"에 해당해 2천만 원 이하면 분리과세로 끝난다.
  (앞서 "국외 배당이라 원천징수되지 않아 무조건 종합과세" 로 본 것은 틀렸다.)
- 금융소득 종합과세 기준 2천만 원 — 소득세법 §14③6 원문 확인. 미성년이라고 달라지는 규정 없음.
- 금융투자소득세 — 소득세법 §87조의2가 **삭제**됐다(2024. 12. 31.). 폐지 확정이라 계산에 영향 없음.

### 7.2 남은 확인 항목

1. 분리과세되는 해외 배당에 외국납부세액을 어떻게 반영하는지. §57(외국납부세액공제)은
   "종합소득금액에 합산되어 있는 경우"를 전제해 분리과세분을 다루지 않는다. 국내 세율 14%가
   미국 원천징수 15%보다 낮아 추가로 뗄 소득세가 없다고 보고 15%만 적용했다. 실제가 15.4%라면
   해외 상장 ETF **분배금 세금 항목만 0.4%p(약 2.7%) 작게** 잡히고 세후 금액 영향은 미미하다.

## 9. 확정된 세부 결정

- **인출 시점 < 증여 종료일**인 경우: 부분 계산하지 않고 **입력 검증으로 막는다.**
  "인출 시점은 증여가 끝난 뒤여야 합니다" 안내를 표시한다. 지급이 남은 상태의 중도 매도는
  유기정기금 계약 자체와 충돌하므로 1단계 범위에서 제외한다.
- **결과 레이아웃**: 세 유형을 **세로 카드로 쌓는다**(모바일 우선). 가로 스크롤 표는 375px에서
  3열이 잘려 비교가 어렵다. 데스크톱에서는 카드가 가로로 배치되도록 CSS만 분기한다.
- **마이너스 수익률을 허용한다** (국내·해외 각각 허용 범위 −20% ~ +20%). 상승만 입력받으면 화면에
  손실 시나리오가 나오지 않아 "투자하면 반드시 불어난다"는 인상을 주고, 이는 §2 "수익을
  제시하지 않는다"는 원칙과 어긋난다. 분배율은 음수가 성립하지 않으므로 0 이상만 받는다.
- **지수별 참고 수익률 표는 추천표가 아니다.** 결과 요약 아래에 기본 접힘으로 두며, 사용자가
  입력값을 정하기 어려울 때 선택할 수 있는 출발점만 제공한다. 기간·산출 기준·출처를 값과 함께
  표시하고 최근 급등 포함/제외 수치를 나란히 둔다. 측정 조건이 서로 달라 행끼리 직접 비교할 수
  없다는 경고를 고정하며, 특정 지수의 강조·추천·우선 정렬은 하지 않는다.
