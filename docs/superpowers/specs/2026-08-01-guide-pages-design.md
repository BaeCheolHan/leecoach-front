# 가이드 페이지 신설 설계 — 유기정기금 증여 신고 가이드

날짜: 2026-08-01 / 승인: 사용자 (대화에서 구두 승인)

## 목적

SEO 검색 유입과 애드센스 심사 대비 콘텐츠 섹션의 첫 페이지.
"유기정기금 증여 전체 흐름(개념→절세 원리→서류 준비→홈택스 신고→FAQ)"을
쉽고 친근한 설명체로 다루고, 메인 도구(계약서 생성기)로 유도하는 CTA를 포함한다.

## 범위

- `/guide` — 가이드 목록 페이지 (글 카드 나열, 현재 1개)
- `/guide/annuity-gift-report` — 신고 가이드 본문
- 메인 페이지 하단에 가이드 링크 추가, sitemap에 URL 2개 추가

## 기술 결정

- **라우팅**: 기존 `/privacy` 방식과 동일한 `main.tsx` pathname 분기 확장.
  라우터 라이브러리 도입 안 함 (페이지 4개 수준, YAGNI).
  분기 로직은 `resolvePage(pathname)` 순수 함수로 분리해 테스트.
- **SEO 메타**: 페이지별 `document.title`·meta description·canonical을 설정하는
  `usePageMeta` 훅. FAQ 섹션은 JSON-LD(FAQPage) 삽입.
- **스타일**: App.css에 `.guide` 본문 타이포 스타일 추가 (기존 토스풍 톤 유지, 모바일 우선).
- **콘텐츠**: TSX 컴포넌트로 작성 (CTA 버튼 등 인터랙션 포함 용이).
  세무 내용은 배포 전 사용자 검수 필수.

## 글 구성

1. 유기정기금 증여란? (목돈 vs 매달 나눠주기)
2. 왜 절세가 되나 (연 3% 할인평가 + 공제한도, 숫자 예시)
3. 서류 준비 (계약서·평가명세서 → 도구 CTA)
4. 홈택스 신고 단계별 (기한·경로·입력·첨부)
5. FAQ 5~6개 (JSON-LD 연동)
6. 면책 문구 + 도구 CTA

## 검증

- `resolvePage`·`usePageMeta` 단위 테스트, 가이드 페이지 렌더 스모크 테스트
- 브라우저에서 라우팅·메타·모바일 레이아웃 실측
- 세무 내용 정확성은 사용자 최종 검수
